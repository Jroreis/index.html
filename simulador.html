Como Usar

  • Adicionar: Arraste os componentes do menu lateral para a área de desenho (planta azul).
  • Mover: Arraste os componentes pela barra superior azul (título) para organizá-los.
  • Fiação: Clique no borne (bolinha) de um componente e, em seguida, clique no borne de outro componente para criar um fio.
  • Apagar: Clique na lixeira vermelha no cabeçalho de um componente para excluí-lo. Clique sobre um fio para deletá-lo.
  • Dica: Construa desde partidas diretas simples até lógicas com CLP e Inversores!
